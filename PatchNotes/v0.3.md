## 0.3.13 - New Features, UI, and Fixes
- Date: 2026-06-19
- Type: Minor
- Authors: Matathias

Adds a few new features, and new UI to more easil engage with the mod.

### Changes
- Expand the "Science outpost link" functionality to be a general resource-linking system, where certain outposts can link to a settlement and forego their item production to instead provide Empire resource production to the settlement
- Add a "Defensive Aura" to Defensive Outposts, only active when they aren't audo-defending or otherwise busy. The aura applies a small military level bonus to all Empire settlements within range
- Add settlement window- and main tab- UI for settlement-outpost linking
- Update some Codex entries

## 0.3.11 - Fixes & Updates
- Date: 2026-06-17
- Type: Minor
- Authors: Matathias

Handful of bugfixes and balance tweaks.

### Changes
- Officially rename the mod to "Empire Refactored: Outposts & Settlements"
- Town outposts can be set to only recruit pawns that match the xenotype or race of the current inhabitants, at a reduced chance of recruitment. Not really an Empire feature, but if we're already touching VOE, then why not?
- Change how military level is calculated: it is now based on similar logic as squads in the base mod, that being level is derived from the cost of all the pawns in the outpost
- Defensive Outpost military efficiency calculations were simplified (it's linear now) with a higher floor and slightly lower ceiling

## 0.3.5 - PlanetTile Update
- Date: 2026-06-03
- Type: Patch
- Authors: Matathias

Updates the mod to use PlanetTile instead of int wherever possible. Rimworld allows for PlanetTile to be cast down to an int, but you lose layer info when you do that, which is a bad thing when it's possible to have Empire settlements on multiple different layers.

### Changes
- Updates the mod to use PlanetTile instead of int
