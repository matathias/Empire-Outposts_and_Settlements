# Empire Refactored: Outposts & Settlements v1.1

## 1.1.1 - Various Fixes
- Date: 2026-07-13
- Type: Patch
- Authors: Matathias

Various bugfixes and minor changes.

### Changes
- Bugfix: when an outpost is set to finance a settlement, payments could succeed even if the player doesn't have enough silver
- When an outpost is converted to a settlement, ship all of the outpost's stored goods to the player instead of destroying them with the outpost
- Bugfix: the new comps for empire settlements would get double-added to any WorldSettlementDef that has multiple parent defs that define a comps node
- Bugfix: some distance calculations wouldn't take planet layers into account
- Bugfix: if an outpost is marked for a raid, but the user saves and loads before the raid arrives, then the outpost loses its IsUnderAttack flag
- Bugfix: defensive auras and encampment bonuses wouldn't apply properly after loading the game
- Bugfix: raids on outposts that end in a player loss could improperly destroy things
- Bugfix: outpost to settlement conversion would skip biome and other tile checks
- Bugfix: when used alongside Specialists & Governors and an outpost is converted into a settlement, pawns could get orphaned in the world pawn ether
- Bugfix: outposts that are linked to a settlement and then destroyed could leave the link data in a bad shape
- Bugfix: when returning pawns to an outpost for whatever reason, pawns could potentially be silently dropped
- Bugfix: UI issues when used alongside Routes & Resources
- Bugfix: outpost conversion to a settlement could send two letters
- Added mod version to the mod settings
